## For the host app

The module runs inside the bank's own app (the host app):

1. The host app owns sign-in, device pairing, PIN setup and reset, the biometrics setting and the session
2. The module hands a session BE ended back to the host app

The host app passes the module two inputs, both through `src/domains/approval/lib/approval-host-inputs/approval-host-inputs.ts`:

1. **Its "Enable Biometrics" setting**, as `biometricApprovalOn` in `approvalSettingsStore`
   1. While off, approval goes straight to the PIN
   2. A session end leaves the setting as the host app set it
2. **A completed PIN reset**, by calling `notifyApprovalPinReset()`
   1. Until then, a device whose PIN BE locked keeps showing the locked message and opens no keypad
